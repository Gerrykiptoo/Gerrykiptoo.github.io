# 🧩 Lab-Based Challenges

## 🔐 Challenge 1: Network Scanning & Threat Mapping
**Problem:** Identify vulnerable endpoints and open ports.  
**Approach:** Used Nmap, Wireshark, and Shodan for reconnaissance.  
**Tools:** Kali Linux, Nmap, Wireshark  
**Lessons Learned:** Improved awareness of endpoint hardening and network visibility.

---

## ⚙️ Challenge 2: CI/CD Automation
**Problem:** Automate deployment of web apps on AWS EC2.  
**Approach:** Designed Docker-based pipeline with GitHub Actions.  
**Tools:** Docker, GitHub Actions, AWS CLI  
**Lessons Learned:** Infrastructure-as-Code is key to efficiency.

---

## 🧠 Challenge 3: Vulnerability Assessment
**Problem:** Scan for common web application vulnerabilities.  
**Approach:** Used OWASP ZAP and Nessus for active scanning.  
**Tools:** OWASP ZAP, Nessus  
**Lessons Learned:** Regular assessments keep systems resilient.
